# 便签本 (Note Pad) v2.0

单文件 PWA 便签工具，支持多笔记、自动保存与 Markdown 预览。

## 🆕 v2.0 更新

- 新增 **多笔记切换**：顶部标签栏新建 / 切换 / 删除笔记，各自独立保存
- 新增 **自动保存状态提示**：小圆点 + 「保存中… / 已保存 HH:MM:SS」
- 新增 **Markdown 预览**：标题、粗体、斜体、删除线、列表、引用、代码块、链接
- 字数统计升级为 **字符 / 词数 / 行数** 三项
- 注入 SOLCAT 彩蛋引擎，UI 全面美化

## 功能

- **即时编辑**：打开即可写，无需登录
- **防抖自动保存**：停止输入 500ms 后落盘，减少长文本写入开销
- **笔记标题**：可自定义标题，标签栏同步显示
- **导出 TXT**：以当前笔记标题命名下载
- **中英文切换**：界面文案同步切换

## 使用方法

1. 打开 `index.html`
2. 输入正文，标题可留空（默认「未命名笔记」）
3. 点「预览」查看 Markdown 渲染效果，点「编辑」返回
4. 点 `+ 新建` 创建下一条笔记；标签上的 `×` 删除当前笔记

> Markdown 预览先对输入做 HTML 转义再渲染，杜绝 XSS。

## 🥚 彩蛋秘籍

| 操作 | 效果 |
|------|------|
| ↑ ↑ ↓ ↓ ← → ← → B A | 全屏彩带烟花 |
| 连点标题 5 次 | 开发者模式面板 |
| 输入 `solcat` 后回车 | 赛博朋克隐藏主题 |
| Ctrl + Shift + T | 切换赛博朋克主题 |

**本作专属**：解锁任意彩蛋后，当前笔记会自动写入一段隐藏 Markdown 内容。

## 技术栈

纯 HTML / CSS / JavaScript，localStorage + Service Worker。
