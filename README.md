# 极简便签 (Note Pad)

一个极简的网页便签工具，无需登录即可随手记录，自动保存到浏览器本地存储。

## 功能

- **即时编辑**：打开即可输入文字，无需登录或注册
- **自动保存**：输入内容 1 秒后自动保存到 localStorage，关闭浏览器不丢失
- **手动保存**：失焦时自动触发保存，底部显示保存时间
- **导出 TXT**：将当前内容导出为 .txt 文件下载
- **新建/清空**：一键新建笔记或清空当前内容（有确认提示）
- **中英文切换**：界面支持中文/英文
- **自动全屏**：打开后自动进入全屏模式，专注写作
- **Esc 退出全屏**

## 使用方法

1. 用浏览器打开 `index.html`
2. 直接在编辑区输入文字
3. 内容自动保存，关闭页面后重新打开仍会恢复
4. 点击"导出TXT"下载为文本文件
5. 点击"新建"开始新笔记

## 技术栈

纯 HTML/CSS/JavaScript，使用 localStorage 持久化数据。
